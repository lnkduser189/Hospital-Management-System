# 🏥 Hospital Appointment Management System

A responsive frontend-based Hospital Appointment Management System that allows patients to view doctors, book appointments, manage appointments, and store appointment data using browser localStorage.

This project is built using **HTML, CSS, and JavaScript** with a focus on clean UI design and real-world appointment management workflow.

---

## 📌 Project Overview

The Hospital Appointment Management System provides an easy-to-use interface for patients to:

- Explore available doctors
- Book appointments
- View booked appointments
- Cancel appointments
- Manage appointment data without a backend using localStorage

The project demonstrates frontend development concepts including DOM manipulation, form handling, responsive design, and browser storage.

---

# ✨ Features

## 🏠 Home Page
- Attractive landing page
- Hospital introduction
- Navigation menu
- Quick appointment booking button

## 👨‍⚕️ Doctor Management
- Display doctor profiles
- Show:
  - Doctor name
  - Specialization
  - Experience
  - Profile images

## 📝 Appointment Booking
Patients can provide:

- Name
- Email
- Select doctor
- Appointment date
- Appointment time

## 📋 Appointment Dashboard
- View all booked appointments
- Display patient and doctor details
- Persistent data storage using localStorage

## ❌ Cancel Appointment
- Cancel unwanted appointments
- Automatically update stored data

## 📱 Responsive Design
- Mobile-friendly layout
- Works across:
  - Desktop
  - Tablet
  - Mobile devices
